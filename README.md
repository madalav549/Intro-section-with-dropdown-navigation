# Frontend Mentor - Intro section page with dropdown navigation

![Design preview for the Intro section with dropdown navigation coding challenge](./preview.jpg)

## Overview

This is my solution to the [Intro section with dropdown navigation challenge on Frontend Mentor](https://www.frontendmentor.io).

This project is a responsive landing page for Snap. It features a dropdown navigation, a sign-in or login button, and a "Learn more" button to find out more about Snap.

## The challenge

The goal was to build the page as closely as possible to the given designs while making it responsive so it could work well across different screen sizes.

The users are able to:

* View the optimal layout for the page depending on their screen size
* See the hover states for all the interactive elements
* Open and close the navigation menu on the mobile and tablet design
* Open the navigation dropdown on any screen size, be it mobile, tablet, or desktop

## Built with

* Semantic HTML5
* CSS custom properties
* CSS Flexbox
* Responsive design
* JavaScript

## What I learned

This project really pushed me more than I expected it to. I spent a lot of time learning about different ways to add individual event listeners to elements that share the same class without being repetitive.

Some of the things I practiced were:

* How to add individual event listeners at once to elements that share a single class name
* Better use of JavaScript loops
* Working with flex-box more

## Continued development

I would like to continue improving my JavaScript and accessibility knowledge. I would also like to refactor parts of the CSS in the future to make the code more maintainable as the project grows.
